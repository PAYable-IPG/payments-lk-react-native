# Changelog

## 0.1.1 (29 September 2026)

The first version on npm. The code is the same as 0.1.0.

- Install with `npm install @payments-lk/react-native`. Every version is built and published by GitHub Actions from https://github.com/PAYable-IPG/payments-lk-react-native, with npm provenance.
- The package carries its licence and links to its source and issues.

## 0.1.0 (15 September 2026)

The first version: `openCheckout` opens a hosted checkout in an authentication sheet with `expo-web-browser`, or in the system browser, and answers the outcome from the return to your app's URL scheme.
